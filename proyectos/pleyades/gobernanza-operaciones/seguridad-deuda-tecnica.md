# 2. Matriz de Seguridad y Gestión de Deuda Técnica

Siguiendo los estándares de transparencia técnica de ingeniería de confiabilidad (SRE) y DevSecOps, esta matriz consolida todos los hallazgos, compensaciones arquitectónicas (*trade-offs*), riesgos aceptados y tareas de hardening del ecosistema **Pléyades**. Cada punto distingue explícitamente entre lo que ya está remediado en el código fuente o manifiestos de GitOps frente a lo proyectado en el roadmap.

---

## 🛡️ Capas de Defensa en Profundidad

```
┌────────────────────────────────────────────────────────┐
│ 1. CÓDIGO (Go 1.24):                                  │
│    - Validaciones Regex invariantes (3-30 chars)       │
│    - Bcrypt Cost 10 + CompareDummy (Timing Attack)     │
│    - Mapeo puro DTOs, cero contraseñas en memoria      │
├────────────────────────────────────────────────────────┤
│ 2. CONTENEDOR (OCI Distroless):                       │
│    - Multi-stage, UID 65532 (nonroot)                  │
│    - Cero shell, cero package manager (10.3 MB)        │
│    - 0 vulnerabilidades High/Critical Trivy            │
├────────────────────────────────────────────────────────┤
│ 3. KUBERNETES & RED (AKS + Cilium eBPF):              │
│    - Ingress HTTP deshabilitado (Cero texto plano)    │
│    - Redirección eBPF O(1) con Kube-Proxy Replacement  │
│    - RBAC segregado (ClusterRole para CRDs, Role para) │
│      Secrets en namespace crossplane-system            │
├────────────────────────────────────────────────────────┤
│ 4. CLOUD IAM & GITOPS (Azure + Entra ID):              │
│    - Zero Static Secrets (Federated OIDC UAMI)         │
│    - Azure Blob Leases (State locking nativo)          │
│    - ArgoCD App-of-Apps con reconciliación declarativa │
└────────────────────────────────────────────────────────┘
```
